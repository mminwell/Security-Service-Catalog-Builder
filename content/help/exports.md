Export the current catalog rows as CSV, Excel, Word, PDF, or JSON. Choose a public or full audience. A file that contains internal fields asks you to confirm first.

The file downloads to your computer. Distribution marking uses the workspace wording when that option is on. Saved audience profiles remember a field list. Admins can set a default format and profile in Workspace settings.
