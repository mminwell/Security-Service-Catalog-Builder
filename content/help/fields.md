Fields and Lookups are Admin pages. A lookup is the list behind a dropdown: teams, statuses, tiers, and the rest. Edit the label, description, and sort order there. Retire an option instead of deleting it, so older services still make sense.

Service code and name stay active. Turning Lookup on for a text field uses the matching lookup list. Those lists belong to the workspace. They are not built into the app.
