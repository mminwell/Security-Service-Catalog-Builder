Templates are pre-built services you can review in a cart and add to the catalog. The page opens as a list. Switch to Cards if you prefer pictures of each template. This browser remembers that choice the next time you visit.

The store includes the original templates and a larger set of fictional services. Search and the domain buttons narrow the list. Physical Security is its own domain. Results are split into pages so the starter packs below stay within reach.

Add all to cart adds every template in the store, not only the current page or domain. It asks first. Templates already in the cart are never added twice, and templates already in the catalog are skipped when that box is checked. Clear cart in the cart drawer removes them in one step.

Checkout copies the chosen templates into the current workspace. You can still edit the result.

On an empty catalog, an Admin can load the fictional starter services instead of shopping the cart.
